# 팀 페루 독서토론 - 회의록 정리 및 시상 스킬

## 개요
팀 페루 독서토론 모임의 녹취록(STT 텍스트)을 정리하고, 시즌별 시상식을 AI로 생성하는 스킬.

## 회의록 정리 프로세스

### 입력 소스 (모두 자동 수집)
아래 데이터를 `scripts/minutes-helper.js`를 통해 DB에서 자동으로 수집한다:
1. **STT 원문** — `meeting_minutes.raw_text` (녹취록 텍스트)
2. **참여자 발제** — `meeting_submissions.discussion` (각 참석자의 발제 질문/내용)
3. **한줄평** — `meeting_submissions.one_liner` (각 참석자의 한줄평)
4. **평점** — `meeting_submissions.rating` (각 참석자의 책 평점)
5. **모임기록** — `meeting_comments` (모임 당일 채팅 기록, 사진 포함)
6. **책 정보** — `books` (제목, 저자, 등록 코멘트)
7. **선정 사유** — `schedules.description` (발제자의 책 선정 사유)
8. **참석자 목록** — `profiles` (이름, 역할)

STT 원문이 메인 소스이고, 나머지는 보조 참고자료로 사용하여 정확도와 풍부함을 높인다.

### 정리 규칙
1. **화자 식별 및 보정**: STT 원문에서 화자가 정확히 인식되지 않는 경우가 많다. 아래 규칙으로 보정:
   - **이름 오류**: 발음이 비슷한 이름으로 잘못 인식 (예: 주영/준영→준용, 성황→성한, 교철→규철) → 참석자 목록 대조하여 보정
   - **번호 화자**: "발화자 8", "발화자 10" 등 숫자로만 표시된 경우 → 발언 내용, 말투, 주제, 이전 대화 맥락을 분석하여 실제 참석자를 추정하여 매칭
   - **미식별 화자**: "알 수 없음", "화자 불명" 등 → 위와 동일하게 맥락 분석으로 보정
   - **보정 근거**: 각 참석자의 관심사, 말투, 직업적 배경, 이전 모임 발언 패턴 등을 종합 활용. DB의 발제/한줄평 데이터로 각 참석자의 관점을 파악한 뒤 대조
   - **보정 불가 시**: 확신이 낮으면 "(추정)" 표시를 붙이고, 정리본 상단에 보정 내역을 간략히 기재
2. **구조화**: 아래 섹션 순서로 정리
   - 발제 — 책 선정 이유
   - 주요 토론 주제별 정리 (번호 매기기)
   - 각자의 평점과 소감
   - 핵심 발제 요약표
   - 마무리
3. **톤**: 구어체를 자연스러운 문어체로 변환하되, 인상적인 발언은 원문 그대로 인용
4. **AI 코멘트**: 각 넘버링 주제가 끝날 때마다 AI가 짧은 코멘트를 남긴다.
   - 형식: `> 🤖 AI 코멘트: [내용]` (인용 블록으로 표시)
   - 톤: 딱딱하지 않고 유머 있게, 친근한 해설자/MC 느낌
   - 내용: 토론 내용에 대한 감상, 재치 있는 요약, 관련 지식 보충, 참석자 발언에 대한 위트 있는 리액션
   - 예시: "유비의 이직 이력을 링크드인에 올리면 헤드헌터가 먼저 연락할 듯 🤣"
5. **논쟁 심판**: 참석자 간 의견이 팽팽하게 갈리는 논점이 있으면:
   - 🔥 이모티콘으로 해당 구간을 표시
   - 양쪽 논점을 공정하게 정리한 뒤
   - `> ⚖️ AI 판결: [내용]` 형식으로 AI가 유머 있게 판결을 내린다
   - 단, 너무 일방적이지 않게 — "OOO의 논리가 한 끗 앞서지만, OOO의 반론도 무시 못 합니다" 식으로 존중하면서 재미있게
   - 예시: "🔥 기뢰 유무 공방 → ⚖️ AI 판결: 준용의 '기뢰 없다' 베팅은 대담하나, 성한의 '하나만 터져도 끝' 논리가 리스크 관리 측면에서 한 수 위. 다만 준용이 맞으면 수익률은 준용 압승 💰"
4. **확장 토론**: 책 내용에서 현실(투자, 직장, 리더십 등)로 확장된 논의도 빠짐없이 포함
5. **곁가지**: 메인 주제에서 파생된 흥미로운 논의는 "곁가지:" 라벨로 따로 표기

### 출력 형식
```
[책 제목] 독서토론 정리

참석: OOO(발제·진행) · OOO · OOO    |    분량: 약 N시간 N분

※ STT 관련 안내

1. 발제 — 왜 「[책 제목]」인가 (발제자)
[내용]

2. [토론 주제 1]
[내용]

3. [토론 주제 2]
[내용]

...

N. 각자의 평점과 소감
[이름] (N점): [소감]

N+1. 마무리
[내용]

핵심 발제 N선과 결론 요약
| 발제 | 핵심 텍스트 | 도달한 통찰 |
```

## 시상식 카테고리

### 정기 시상 (시즌: 분기/반기/연간)
모임별 회의록 + 발제/한줄평/평점 데이터를 종합 분석하여 수상자 선정.

| 상 이름 | 기준 | 데이터 소스 |
|---------|------|------------|
| 🏆 MVP | 토론 기여도 종합 1위 | 회의록 발언량 + 발제 깊이 + 댓글 활동 |
| 📚 참여상 | 가장 많은 모임 참여/발제 | meeting_submissions + attendances 카운트 |
| 💬 명언상 | 가장 인상적인 한줄평 | one_liner 텍스트 AI 분석 |
| 🔥 열정상 | 출석률 + 제출률 최고 | attendances + submissions |
| 😂 분위기메이커상 | 회의록에서 웃음/유머 빈도 | 회의록 텍스트 분석 |
| 🎯 혜안상 | 가장 날카로운 발제 질문 | discussion 텍스트 AI 분석 |
| 📖 베스트 발제자상 | 가장 깊이 있는 발제 | 회의록 내 발제 섹션 AI 분석 |
| 🌟 성장상 | 시즌 초 대비 토론 참여/깊이 성장 | 시계열 비교 |

### 특별 시상 (모임별)
- 🗡️ 날카로운 칼날상: 그날 가장 날카로운 질문/반론을 던진 사람
- 🌊 토론 확장상: 책 내용을 현실/다른 분야로 가장 잘 연결한 사람
- 📝 성실상: 발제·평점·한줄평 모두 꼼꼼히 작성한 사람

### AI 즉석 시상 (자동 생성)
위 고정 카테고리 외에, AI가 회의록을 분석한 뒤 그 모임/시즌에만 해당하는 **즉석 상**을 자유롭게 만들어 부여한다.
- 상 이름, 수상자, 근거를 AI가 직접 작명하고 선정
- 재미있고 개성 있는 네이밍 권장 (예: "🦔 고슴도치상 — 한 주제를 끝까지 파고든 OOO", "🔮 예언자상 — 시장 흐름을 정확히 짚은 OOO")
- 회의록에서 발견되는 독특한 패턴, 인상적인 장면, 웃긴 순간, 날카로운 통찰 등을 기반으로 선정
- 매 모임/시즌마다 다른 상이 나올 수 있음 (반복 금지, 매번 새롭게)
- 고정 시상과 합쳐서 한 사람이 여러 상을 받을 수 있음

## 참여자별 대화량 분석

회의록 원문을 기반으로 각 참석자의 대화량을 백분율로 산출한다.

### 분석 방법
1. 회의록에서 화자별 발언 블록을 식별
2. 각 화자의 총 글자 수(공백 제외) 집계
3. 전체 대화량 대비 각 화자의 비율을 백분율로 산출
4. 발언 횟수(턴 수)도 별도 집계

### 출력 형식
```
📊 대화량 분석

| 참석자 | 글자 수 | 비율 | 발언 횟수 | 역할 |
|--------|---------|------|-----------|------|
| 성한   | 12,340  | 42%  | 87턴      | 발제·진행 |
| 성근   | 7,210   | 25%  | 53턴      | 참여 |
| 규철   | 5,830   | 20%  | 41턴      | 참여 |
| 준용   | 3,920   | 13%  | 29턴      | 참여 |

💡 분석 코멘트:
- 발제자(성한)가 전체의 42%를 차지, 진행 역할 포함 고려하면 적정 수준
- 성근이 비발제자 중 가장 활발, 특히 리더십 주제에서 집중적 발언
- 준용은 발언 빈도는 낮으나 한마디할 때 임팩트가 큼
```

### 활용
- 시상식 MVP 선정의 정량 근거
- 시즌별 추이 분석 (특정 멤버의 참여도 변화 추적)
- 토론 균형도 확인 (한 사람이 70% 이상이면 진행 개선 필요 등)

## 시상식 생성 프로세스

### 입력
- 해당 시즌의 모든 회의록 텍스트
- DB 데이터: submissions, attendances, comments, ratings

### AI 분석 단계
1. 각 회의록에서 참석자별 발언량, 주요 발언, 질문 수 추출
2. 발제/한줄평 텍스트의 깊이·창의성·인사이트 평가
3. 정량 데이터(출석률, 제출률, 평균 평점) 집계
4. 카테고리별 후보자 선정 및 수상 근거 작성

### 출력 형식
```
🏆 팀 페루 독서토론 [시즌] 시상식 🏆

[상 이름]
수상자: [이름]
수상 근거: [AI가 분석한 구체적 근거]
명장면: "[회의록에서 발췌한 인용]"

...

📊 시즌 통계
- 총 모임 횟수: N회
- 총 참석 인원: N명
- 평균 토론 시간: N시간
- 가장 높은 평점을 받은 책: [책 이름] (N점)
```

## 데이터 구조 (Supabase)

### meeting_minutes 테이블 (신규)
```sql
CREATE TABLE meeting_minutes (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  schedule_id UUID REFERENCES schedules(id) ON DELETE CASCADE,
  raw_text TEXT,           -- STT 원문
  summary TEXT,            -- AI 정리본
  created_by UUID REFERENCES profiles(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### meeting_awards 테이블 (신규)
```sql
CREATE TABLE meeting_awards (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  schedule_id UUID REFERENCES schedules(id) ON DELETE CASCADE NULL,
  season VARCHAR(50),      -- '2026-Q1', '2026-H1', '2026' 등
  award_type VARCHAR(50),  -- 'mvp', 'best_quote', 'passion' 등
  user_id UUID REFERENCES profiles(id),
  reason TEXT,
  quote TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 참고: 삼국지 촉지 회의록 분석 (실제 데이터)

### 참석자별 특성 (1회차 기준)
- **성한**: 발제자, 깊이 있는 역사 배경 설명, 투자·시사 연결 능력 탁월
- **성근**: 만화/게임 등 다양한 매체 경험, 리더십·조직론에 관심, 통찰력 있는 비유
- **규철**: 창업 경험, 실용적 관점의 질문("강점이 약점이 되는가"), 에너지/투자 논의
- **준용**: 솔직한 평가(1.5점), 현실적 관점, 서비스 업무 경험 기반 리더십 견해

### 토론 패턴
- 책 내용 → 현대 비유 → 투자/직장 → 다시 책으로 순환
- 후반부에 시사/투자 토론으로 자연스럽게 확장 (이것도 기록 가치 있음)
- 발제 질문이 토론의 깊이를 좌우함
